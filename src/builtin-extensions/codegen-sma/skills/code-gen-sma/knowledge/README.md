# 项目知识目录说明

> 此目录存放与项目开发相关的任意文档。不限制文档类型、格式或内容。

## 可存放的内容示例

- 模块功能说明
- 接口调用方式和参数说明
- 数据表结构说明
- 环境变量和配置说明
- 编译构建指南
- 编码规范和约定
- 架构设计文档
- 部署运维手册
- 常见问题 FAQ
- 业务规则说明
- 任何对开发有帮助的文档

## 使用方式

1. 将项目相关的文档放入此目录（或子目录）
2. 文件格式不限：`.md` / `.txt` / `.yaml` / `.json` 等均可
3. 可以创建子目录进行分类（如 `modules/`、`design/` 等）
4. 编码过程中，大模型会自动检索此目录下的内容
